# FUTURE_PE_03 — Portfolio Website

**AI SEO Blog & Content Cluster Generator** · Prompt Engineering (PE)

## Run

```bash
cd website
npm install
npm run dev
```

http://localhost:5173

## Build

```bash
npm run build
```

Deploy `dist/` to Vercel, Netlify, or GitHub Pages.

## Customize

Edit `src/data/content.js` — set `GITHUB_URL`, `LINKEDIN_URL`, `EMAIL`.

## Stack

React 18 · Vite 6 · Tailwind CSS · Framer Motion · Lucide
