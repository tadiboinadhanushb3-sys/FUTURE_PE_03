## Project purpose

Demonstrates how **ChatGPT**, **Claude**, and **Gemini** — combined with structured **prompt engineering** — generate:

- SEO-optimized blog posts
- Content clusters (pillar + supporting articles)
- Keyword intent maps
- Local SEO pages
- Internal linking strategies
